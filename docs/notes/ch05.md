## 構成の判断（ページ統合・分割、ox の対応付けで迷ったもの）
- ページ統合は行わず、`####` 1つ=1ページ。400字未満のページが20ページあり警告になるが、`src` の連続性・逐語転記を優先して統合しなかった。
- §2「試験での出方」は 1,870 字のため2ページに分割（偏りを避けるため上限 1,000 字で最上位箇条書きの境目分割。タイトルは「試験での出方」「試験での出方（続き）」）。
- レッスン: L1 S3 基本〜レプリケーション（8頁）、L2 S3 転送〜EBS・インスタンスストア（12頁）、L3 EFS/FSx〜移行（9頁）、L4 試験での出方と暗記数字（3頁）。
- 最終レッスンにも ox を置くため、Q11（プレフィックスごと 5,500 GET：数字の問題）を「暗記すべき数字・制限」ページに対応付けた。
- Q18（Multi-Attach）は EBS ボリュームタイプ（SSD）、Q23（Tape Gateway）は Storage Gateway ページに対応付けた。
